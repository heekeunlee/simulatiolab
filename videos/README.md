# videos/ — 영상 제작 작업 폴더

영상 파일은 **용량이 커서 깃에 올리지 않습니다.** 완성본은 유튜브에 올리고, 사이트에는 링크나 임베드만 넣습니다.

| 폴더 | 내용 | 깃 |
|---|---|---|
| `scripts/` | 영상별 대본·구성안 (`NN-slug.md`, 예: `01-talent-vs-luck.md`) | 올림 |
| `thumbnails/` | 썸네일 PNG (파일당 1MB 이하 권장) | 올림 |
| `raw/` | 화면 녹화 원본 | **무시** |
| `render/` | 편집·렌더링 결과(mp4 등) | **무시** |
| `assets/` | 음악·효과음·폰트·큰 이미지 등 소스 | **무시** |
| `tmp/` | 임시 파일 | **무시** |

원본·결과물 백업은 맥미니 외장 디스크나 클라우드(Google Drive, Cloudflare R2 등)에 따로 하세요.
`raw/ render/ assets/` 안의 파일은 `.gitignore`가 막아 줍니다. 그 밖의 폴더에 mp4가 있어도 확장자 규칙으로 막힙니다.

## 영상별 대본 틀

```
# NN. 제목
- 실험: site/experiments/<slug>/ (설정: ?s=… 링크)
- 한 줄 훅:
- 구성: 도입(질문) → 실험(변수 바꾸기) → 반전(결과) → 해석 → 한계 → 다음 편 예고
- 사용 수치: tools/validate-<slug>.js 출력에서 가져온 것만
- 설명란 링크: 사이트 주소, 투표 안내
```
