# 실험 아이콘 스타일 규칙 (시안)

모든 실험 아이콘이 같은 규칙을 따른다. 칸에서는 72~110px로 보이므로 굵고 단순하게.

## 틀
- `viewBox="0 0 512 512"`, 둥근 사각형 `rx="118"` (한 변의 약 23%). 칸 CSS도 `border-radius: 23%`로 맞춘다.
- 바탕: 분야색 기준 세로 그라데이션. 위 = HSL 밝기 +8%, 아래 = 밝기 −6% (채도·색상 유지).
- 광택: 위쪽 0~200px 영역에 흰색 세로 그라데이션(불투명도 0.16 → 0). 아래 경계는 살짝 휜 곡선.
- 그림자·테두리는 SVG에 넣지 않는다 (칸 CSS가 처리).
- 글자·숫자 없음.

## 그림
- 핵심 모양 **하나**. 가운데 약 60% 영역(대략 x·y 100~410) 안에.
- 오른쪽 위·왼쪽 위 구석(약 90px)은 칸 표시(번호판, New·3D)가 올라가므로 중요한 부분을 두지 않는다.
- 선 두께: 기본 28 (화살표처럼 강조할 선은 32), 끝·모서리는 둥글게(`round`).
- 면 모서리: 작은 사각형은 rx 4~6, 큰 사각형은 rx 16~20.
- 색은 최대 3가지:
  - 흰색 `#fff` — 주인공 모양
  - 크림색 `#fff3d1` — 포인트 1곳(가장 앞 새, 창, 되갚는 화살표, 불빛)
  - 분야색의 밝은 변형 — 보조 모양(밝기 +40%, 채도 ×0.6)
  - 필요할 때만: 분야색의 짙은 변형(밤하늘, 꺼진 집)
- 빛 번짐은 `radialGradient`(크림색, 가운데 0.95 → 바깥 0).
- 각 SVG의 `id`는 실험 기호로 접두어를 붙여 겹치지 않게 (`mm-bg`, `ff-glow` …).

## 칸(새 틀) CSS 값
- 아이콘 모서리 `border-radius: 23%`, 테두리선 없음.
- 그림자 두 겹: `0 12px 24px -8px rgba(20,30,60,.22), 0 2px 5px rgba(20,30,60,.10)`
- 올렸을 때: `translateY(-4px)` + `0 18px 32px -8px rgba(20,30,60,.28), 0 3px 7px rgba(20,30,60,.12)`
- 사진을 쓸 때: 분야색 14% 덮기 + 아래 45%부터 `rgba(10,16,30,.24)`까지 어둡게.
- 이름은 아이콘 아래 가운데 12px, 두 줄까지.
