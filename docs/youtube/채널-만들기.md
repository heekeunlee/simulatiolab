# 유튜브 채널 만들기 (시뮬라티오 랩, @simulatiolab)

채널 생성은 본인 구글 계정으로 로그인해서 약관에 동의해야 하므로 직접 하셔야 합니다. 아래 순서대로 하시면 약 10~15분 걸립니다.
메뉴 이름은 유튜브가 바꿀 수 있어서 화면과 조금 다를 수 있습니다.

## 준비물 (이 폴더에 있음)

- `profile-800.png` — 프로필 사진 (800×800)
- `banner-2560x1440.png` — 채널 배너 (2560×1440, 글자는 가운데 안전 영역 안에 있음)
- 아래 "복사해서 붙여넣을 문구"

## 단계

1. **구글 계정 정하기**
   - 개인 계정(clzmyiz@gmail.com)으로 바로 만들 수도 있고, 나중에 다른 사람과 함께 관리할 계획이면 **브랜드 계정**으로 만드는 편이 편합니다 (채널 만들기 화면에서 "맞춤 이름 사용"을 고르면 브랜드 계정이 됩니다).
2. **채널 만들기**
   - https://www.youtube.com 에 로그인 → 오른쪽 위 프로필 사진 → **채널 만들기** (또는 "내 채널" → 채널 만들기)
   - 채널 이름: `시뮬라티오 랩 | 세상을 돌려보는 실험실`
   - 핸들: `@simulatiolab` 입력 → "사용 가능"이라고 뜨면 **채널 만들기**
   - 2026-10-10 확인 시 `youtube.com/@simulatiolab` 주소가 열리지 않았으므로 비어 있을 가능성이 높습니다. 다른 사람이 먼저 쓰고 있으면 `@simulatio_lab` 같은 대안을 쓰고 저에게 알려 주세요.
3. **프로필과 배너 올리기**
   - 오른쪽 위 프로필 → **YouTube 스튜디오** → 왼쪽 메뉴 **맞춤설정** → **브랜딩** 탭
   - 사진: `profile-800.png`, 배너 이미지: `banner-2560x1440.png`
4. **기본 정보 채우기** (같은 맞춤설정의 **기본 정보** 탭)
   - 설명: 아래 문구 붙여넣기
   - 링크 추가: 제목 `직접 돌려보기 / Try it yourself`, 주소 `https://heekeunlee.github.io/simulatiolab/`
   - 문의용 이메일: 공개되므로 정말 공개해도 되는 주소만 넣으세요 (스팸 수집에 노출됩니다)
5. **채널 설정** (스튜디오 왼쪽 아래 **설정** → **채널** → 기본 정보)
   - 국가: 대한민국, 키워드: 아래 목록, 시청자층: "아동용이 아님"
6. **전화번호 인증** (https://www.youtube.com/verify)
   - 인증하면 15분 넘는 영상 업로드와 맞춤 썸네일을 쓸 수 있습니다.
7. **영어 자막과 번역 준비** (전 세계 구독자용)
   - 영상을 올린 뒤 스튜디오 **자막**에서 영어 자막을 추가하고, 제목·설명도 영어 번역을 추가할 수 있습니다. 사이트의 영어 문구를 그대로 재사용하면 됩니다.
8. **사이트와 연결 확인**
   - 사이트 맨 아래에는 이미 `youtube.com/@simulatiolab` 링크가 있습니다. 핸들을 다르게 정했다면 알려 주세요. 바로 고치겠습니다.
9. **첫 영상 올리기 전 점검**: 제목, 설명(사이트 링크를 첫 줄에), 썸네일, 영어 자막, 시청자층 설정
