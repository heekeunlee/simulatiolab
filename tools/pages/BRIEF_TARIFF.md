# 새 실험 1개: 관세 보복 (뉴스 기반 구조 실험) (2026-10-14)

운영자(이희근) 요청: 요즘 뉴스의 "관세 갈등"에서 **구조**만 뽑아 "서로 보복하면 모두 손해인데 왜 멈추지 못할까?"를 시뮬레이션한다. **특정 나라·사건·정치인·실제 관세율을 쓰지 않는다**(두 나라 "A국/B국" 또는 "우리 나라/상대 나라"). 예측·처방·정치적 편들기 금지.

`tools/pages/BRIEF_ART6.md`를 **그대로 따른다**(규칙 1~10, 검증, 보고 JSON 모양, 번역은 ko/en만). 먼저 그 문서와 `BRIEF_NEW11.md`, `BRIEF_HEADLINES4.md`, `BRIEF_HEADLINES5.md`를 읽는다. 참고 구현: `site/experiments/cooperation`(반복 죄수의 딜레마), `commons`, 최근 `queue`/`hagwon`. 예술 전용 규칙(취향 단정 금지)만 "정치·경제 가치 판단 단정 금지"로 바꿔 읽는다.

- slug: `tariff`, 기호는 **Tf**(안 쓰임. 겹치면 다른 조합), 분야는 경제(`economy`)에 들어갈 것(등록은 호출한 쪽).
- 후킹 제목 후보: "관세 보복을 서로 주고받으면 왜 둘 다 손해일까?" / "먼저 올린 쪽이 이길까, 둘 다 질까?" (영어도 같은 후킹)

## 모델 (단순화·예시임을 페이지에 밝힌다)
- 두 나라가 매 라운드(분기) 관세를 올릴지/유지/내릴지 정한다. 한 나라의 이득 = 수출 이익 − 수입품 값 상승으로 인한 소비자·기업 부담 + (자기 관세로 거둔 이익 일부). 상대가 관세를 올리면 내 수출이 줄고, 내 관세는 자국 소비자 부담을 늘린다. 두 나라가 동시에 올리면 둘 다 **서로 안 올렸을 때보다 손해**지만, 상대가 안 올릴 때 나만 올리면 단기 이득이 되도록 수치를 잡는다(죄수의 딜레마 구조, 그러나 연속 단계의 관세율 0~50%).
- 행동 규칙(슬라이더로 바꾼다): `보복하는 정도`(상대가 올린 만큼 얼마나 따라 올리나 0~150%), `참을성`(몇 라운드 협상 신호를 보면 내리나), `국내 압력`(내리기 어렵게 하는 정도), `협상 시도 빈도`. 라운드 100번.
- 판 이름 `seedLabel`: 번호 없는 짧은 명사(예: '무역 갈등'). 실험은 "같은 설정, 다른 운(우연한 충격)"으로 여러 판을 비교.
- 비교(집계): 보복하는 정도 0%, 50%, 100%, 150%에서 100판 평균 "두 나라 합계 이득", 평균 관세율, 갈등이 끝나는(양국 관세 10% 이하로 복귀) 판 비율. validate 스크립트로 수치를 먼저 확인하고, **화면에 쓴 숫자는 모두 validate 출력과 일치**.

## 화면
- ① 왼쪽: 두 나라(큼직한 두 덩이, 사람 픽토그램 몇 명씩 또는 상자)와 가운데 무역선(화물 상자 흐름, 굵기=거래량). 관세가 오르면 선이 가늘어지고 양쪽 "소비자 부담" 표시가 커진다. 현재 관세율 큰 숫자 칩(선으로 연결된 이름표). 모양 종류 2개 이하.
- ② 아래 차트: 시간별 양국 관세율 선(재생 시점까지), ③ 시간별 누적 이득(두 나라 각각 + "서로 안 올렸다면" 기준선은 **재생 시점까지만**; 미래 결과를 미리 보이지 않기), ④ 보복 정도별 비교(집계 sweep, 이름에 집계임 표시). 범례는 그래프 아래, 축 이름·단위.
- 재생·그래프 동기화(규칙 6) 필수. 통계 카드: 지금 관세율, 합계 이득 차이.
