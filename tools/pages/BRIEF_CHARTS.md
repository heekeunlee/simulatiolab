# 그래프 축 이름·범례 정리 + 쉬운 말 다듬기 (2026-10-13)

실험 1개(또는 몇 개)를 맡아 아래 두 가지를 한다. 맡은 slug의 파일만 고친다: `tools/pages/<slug>.py`(직접 쓴 HTML 페이지는 `site/experiments/<slug>/index.html`), `site/experiments/<slug>/app.js`·`app3d.js`, `tools/pages/dyn_<slug>.py`(기존 11개 실험은 `tools/i18n/en_dyn.py`), 그리고 새로 만드는 `tools/pages/simple/<slug>.json`. **공용 파일(`site/lib.js`, `site/style.css`, `layout.js`, `index.py`, `predict.py`, `daily.py` 등)은 고치지 않는다.** 공용 도구가 부족하면 보고에 적는다. 커밋하지 않는다.

## A. 그래프: 축 이름은 축 옆에, 범례는 그래프 안에
1. **축 이름(단위 포함)**: 축이 있는 그래프(선·막대·산점도·히스토그램 등)는 **y축 이름은 축 맨 위(왼쪽), x축 이름은 축 오른쪽 끝 아래**에 표시한다. 이미 있는 `Lab.chart()`/`Lab.axes(c, { …, xLabel, yLabel })` 또는 `Lab.axisNames(c, xLabel, yLabel)`을 쓴다(`site/lib.js` 참고; `chart()`의 위쪽 여백 기본값이 24로 늘었다. 직접 margin을 주는 그래프는 `t ≥ 24`, `b ≥ 36`을 지킨다). 이름은 짧게 + 단위를 괄호로: `걸음 수 (걸음)`, `평균 대기시간 (분)`, `비율 (%)`, `시간 (년)`, `격차 (배)`. 단위가 없으면 `(없음)`을 쓰지 말고 "점수", "지수"처럼 이름만. 지도·격자·네트워크·애니메이션 장면처럼 축이 없는 그림은 축 이름 없이 범례만.
   - 기존에 직접 `fillText`로 회전해서 쓰던 y축 이름, 캔버스 안/아래의 "가로축은…" 같은 안내 글자는 같은 방식(위 왼쪽 / 오른쪽 아래)으로 바꿔 한 가지 모양으로 통일한다. 눈금 숫자와 겹치지 않게 한다.
2. **범례는 그래프 안**: 색·선 모양·점·막대의 뜻은 캔버스 안에서 `Lab.legend(c, [{kind:'line'|'dash'|'dot'|'box', color, label}], pos)`로 그린다(`pos` = 'tr'|'tl'|'br'|'bl', 데이터를 가리지 않는 구석). 그래프 그리기의 **맨 마지막**에 부른다. 페이지 .py의 HTML 범례(`legend=[leg(...)]`)와 `note`로 대신하던 색 설명은 **지운다**(그래프 아래의 실시간 숫자 안내 `note`는 범례가 아니면 둔다). 범례가 필요 없는 그래프(선 하나)는 만들지 않는다.
3. 캔버스에 쓰는 모든 새 글자(축 이름, 범례 글자)는 `dyn_<slug>.py`의 `DYN`에 `'한국어': 'English'`로 넣는다(영어는 단위까지 자연스럽게: 'Steps (steps)' → 'Steps taken'처럼 중복 피하고 간결하게). 같은 한국어 키가 다른 영어로 이미 있으면 새 키를 만들어 구분한다.
4. 휴대폰(390px 폭)에서 글자가 잘리거나 겹치지 않는지, 범례 상자가 핵심 데이터를 가리지 않는지 확인한다.

## B. 쉬운 말로 다듬기
읽는 사람은 **중학생~일반 성인**이다. "무지의 베일 뒤에서 어떤 사회를 고를까" 같은 표현은 어렵다. 아래를 쉬운 말로 다시 쓴다(한국어와 영어 모두, 뜻·숫자·주장 강도는 그대로):
- 페이지 `title`, `title_tag`, `desc`, `lead`, 슬라이더 이름·도움말, 차트 제목과 설명, 통계 카드 라벨, "모델은 이렇게 움직입니다" 목록. (**이론적 근거·이론 칸, 헤드라인(`tools/pages/headlines/`), '말하는 것/말하지 않는 것'은 건드리지 않는다.**)
- 규칙: 한자어·전문용어를 줄이고 일상 말로("균형"→"안정된 상태", "임계"→"한계선", "편향"→"한쪽으로 쏠림", "되먹임"→"서로 영향을 주고받음", "확산"→"퍼짐"). 꼭 필요한 용어는 처음 한 번 괄호로 풀이한다(예: "무지의 베일(내가 누구로 태어날지 모르는 상태)"). 한 문장은 짧게, 질문형 제목은 우리 생활 장면으로("내가 누구로 태어날지 모른다면 어떤 사회를 고를까?"). 영어도 쉬운 단어와 짧은 문장.
- **제목은 후킹이 있되 어렵지 않게.** 학술 용어가 제목에 있으면 쉬운 말로 풀고 용어는 본문에서 소개한다.
- 새 문구는 모두 `T('한국어','English')` 이중 문구(페이지) 또는 `dyn_<slug>.py`(캔버스·실행 중 문구)로.

메인 페이지 칸(주기율표 타일)에 쓸 문구를 `tools/pages/simple/<slug>.json`로 만든다(UTF-8):
`{"title_ko": "…", "title_en": "…", "desc_ko": "…", "desc_en": "…"}` — `title`은 페이지 제목과 같게(또는 더 짧게), `desc`는 두세 문장 이내(한국어 90자 안팎)로 쉽게, 결과를 미리 다 말하지 말고 궁금하게.

## 검증
`export NODE_PATH=~/.simlab-tools/node_modules`, 프로젝트 루트에서: ① `python3 tools/pages/<slug>.py && python3 tools/i18n/build_dyn.py` ② `node tools/browser/check.js <slug> ko,en 4000`(통과) ③ `node tools/browser/shoot.js <slug> --wait=5000 --out=$HOME/.simlab-tools/shots/<slug>`(결과 그래프를 Read로 직접 보고, 예상 게이트가 막으면 `.pskip`을 눌러 건너뛴다)와 휴대폰 `--mobile=1 --w=390 --h=844`로 축 이름·범례가 보이는지 확인. ④ `node tools/validate-<slug>.js`가 있으면 숫자가 그대로인지 확인(시뮬레이션 계산을 바꾸지 않는다).
