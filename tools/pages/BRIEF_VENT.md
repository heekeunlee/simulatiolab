# 새 실험 1개: 환기 (문과 창문 배치) — 2D + 3D (2026-10-14)

운영자(이희근) 요청: "문과 창문을 어떻게 배치해야 환기가 잘 되는지" 시뮬레이션. **2D와 3D 모두 시각화**한다.

`tools/pages/BRIEF_ART6.md`(규칙 1~10, 검증, 보고 JSON 모양, 번역은 ko/en만)와 `tools/pages/BRIEF_3D5.md`(3D 요구사항)를 **그대로 따른다**. 먼저 두 문서와 `BRIEF_NEW11.md`, `BRIEF_HEADLINES4.md`, `BRIEF_HEADLINES5.md`를 읽는다. 참고: 3D가 들어간 `site/experiments/firefly`·`sunflower`·`sandpile`(app3d.js, 생성기 `tools/pages/<slug>.py`의 `three=True` 섹션), `tools/pages/BRIEF_TARIFF.md`(새 실험 한 개를 만든 방식, `new_art/<slug>.json` 보고 모양). 예술 전용 규칙은 "건강·건축 처방 단정 금지"로 바꿔 읽는다.

- slug: `ventilation`, 기호 **Vt**(안 쓰임), 분야는 `daily`(일상의 선택과 질서)(등록은 호출한 쪽).

## 모델 (단순화·예시임을 페이지에 밝힌다)
- **위에서 내려다본 방 한 칸의 2D 평면**(격자 예: 60×40칸). 벽, 바깥, 열린 창/문(틈), 가구 없음(옵션: 가운데 벽 하나 = "방문 닫음").
- 바깥 바람이 한 방향에서 분다(정면/옆/비스듬히 선택). 열린 곳으로 공기가 들어오고 나간다. 공기 흐름은 **비압축 2D 격자 유체**(예: 격자 볼츠만 D2Q9 또는 정상 퍼텐셜 흐름 + 확산)로 계산하고, 방 안 오염물(예: 사람이 내쉰 공기=이산화탄소)의 **농도가 흐름에 실려 이동·확산**한다. 계산이 안정적이고 가벼워야 한다(휴대폰 포함). 새 물리 상수를 지어내지 말고 무차원 설정으로 두며, 숫자는 모두 "이 모델에서의 예시"로.
- 사용자가 바꾸는 것(슬라이더/선택, 쉬운 말): `창문(열린 곳) 개수 1~3`, `열린 곳 위치`(같은 벽 / 마주 보는 벽 / 옆 벽 — 선택 또는 위치 슬라이더), `열린 틈의 크기`, `바람 세기`, `바람 방향`, `방문(가운데 벽) 열기/닫기`, `오염원 위치`(방 한가운데/구석).
- 핵심 비교(집계 sweep, 이름에 집계임을 표시): 같은 벽에 창 2개 vs 마주 보는 벽에 창 2개 vs 옆 벽 2개, 창 하나(단측 환기) — 지표: ① **방 안 공기가 절반으로 맑아지는 데 걸리는 시간**, ② **방 안 공기가 얼마나 구석구석 바뀌는가(정체된 구석의 비율)**. 바람 세기·방향별로도.
- 지표 정의를 페이지에 쉬운 말로 설명(전문 용어 'ACH' 등은 이론 메모에만).
- 판 이름 `seedLabel`: 번호 없는 짧은 명사(예: '배치'). 같은 설정, 다른 오염원 위치 등으로 반복.
- **정직성**: 이 모델은 위에서 내려다본 2D 단순 모델이다. 높이 방향 흐름, 온도 차로 인한 상승 기류(굴뚝 효과), 가구·사람, 난류, 실제 건물 규정·건강 기준은 없다. "어떤 배치가 법적·의학적으로 충분하다"고 단정하거나 처방하지 않는다. 출처는 확실한 일반 개념(맞통풍 cross ventilation은 일반적으로 같은 벽 단측 환기보다 환기량이 크다고 알려져 있다 등)만 "~라고 알려져 있어요"로, 특정 논문 인용은 확신 없으면 쓰지 않는다. 그리고 **이 모델의 결과가 위 일반 지식과 같은 방향인지 validate로 직접 확인**하고 달라지면 있는 그대로 보고한다.

## 화면
- ① 2D 평면: 방 윤곽, 열린 창/문 위치(이름표 칩: "창 1", "바람 →" 큰 화살표), 공기 흐름(작은 입자가 흐름을 따라 움직임 또는 유선), 색 = 공기 상태(탁함↔맑음) 면 색(색 2~3종). 사람 픽토그램 1~2명이 오염원일 수 있음(작은 `personPath`). 모양 종류 2개 이하.
- ② 3D: BRIEF_3D5 요구(같은 상태를 읽고 새 계산 없음). 방을 위로 세운 입체(벽 높이, 창/문 구멍이 뚫린 벽, 투명한 벽면), 바닥에 흐름 입자와 농도 색, 드래그 회전. 재생·그래프와 동기화, 스포일러 금지.
- ③ 그래프(재생 시점까지만 자란다): 시간별 방 평균 탁함(이산화탄소 같은 오염 농도 지수 0~100), ④ 배치별 비교(집계), ⑤ 바람 세기/방향별 비교(집계). 축 이름·단위, 범례는 그래프 아래. 통계 카드: 지금 평균 탁함, 절반이 되는 데 걸린 시간(도달 전엔 빈 문자열, 숫자 패턴에 '–' 금지).
- 대비형 헤드라인(BRIEF_HEADLINES5, 이 모델이 실제로 보여 준 것만; 경우를 갈라): 예: "마주 보는 벽에 열면 공기가 가로질러 빨리 바뀌고, 같은 벽에 열면 입구 근처만 바뀌고 구석은 오래 남아요" 같은 식. 모델에 없는 것(온도, 높이, 난류, 규정)은 not에.
