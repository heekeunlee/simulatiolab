# 결과 해석 한 줄 요약 만들기 (2026-10-13)

각 실험 페이지 아래 "이 결과가 말하는 것 / 말하지 않는 것" 상자가 서술이 길어서 읽기 어렵다. **각 상자에 한 줄짜리 헤드라인**을 만들고, 기존 긴 설명은 "상세 설명" 버튼 뒤로 접는다. 너는 헤드라인 문구만 만든다.

## 입력 읽는 법
슬러그마다 `site/experiments/<slug>/index.html` 안의 `<div class="callout" data-en="...">` 두 개가 대상이다(첫째 = 말하는 것, 둘째 = 말하지 않는 것). 한국어는 태그 안 본문, 영어는 `data-en` 속성. 아래 명령으로 보면 편하다:
`python3 - <<'P'
import re,html,sys
s=open('site/experiments/<slug>/index.html',encoding='utf-8').read()
for m in re.finditer(r'<div class="callout" data-en="([^"]*)">(.*?)</div>',s,re.S): print(html.unescape(re.sub('<[^>]+>','',m.group(2)))); print('EN:',html.unescape(re.sub('<[^>]+>','',html.unescape(m.group(1))))); print()
P`

## 쓸 것
슬러그마다 `tools/pages/headlines/<slug>.json` 하나(UTF-8):
`{"says_ko": "...", "says_en": "...", "not_ko": "...", "not_en": "..."}`
- 헤드라인은 **한 문장**, 한국어 45자 안팎(최대 55자) · 영어 90자 안팎(최대 110자). 라벨("말하는 것:")은 쓰지 않는다 — 화면이 따로 붙인다.
- **핵심 결과 하나**를 말한다. 원문에 나온 숫자·사실만 쓴다(새 수치·새 주장 추가 금지, 원문 주장의 강도 유지: "일 수 있다"를 "이다"로 바꾸지 않는다).
- "말하지 않는 것"은 가장 중요한 한계/오해 방지 한 가지를 한 문장으로("…를 뜻하지는 않아요", "…까지 증명하지는 않아요" 식). 원문의 의학·투자·교육 면책 문구가 있으면 그 취지를 헤드라인에도 살린다.
- 말투: 이 사이트의 친절한 해요체/합니다체 중 원문에 맞춰 통일, 쉬운 말, 군더더기 없이. 영어는 같은 뜻의 자연스러운 한 문장.
- HTML 태그 쓰지 않는다(`<b>`, `<code>` 금지). 따옴표는 일반 따옴표.
- 정직성: 원문이 "이론과 안 맞는다/재현 안 됐다"고 한 것을 헤드라인이 부풀리지 않는다.

## 마무리
각 파일을 `python3 -c "import json;json.load(open(path))"`로 확인하고, 한 줄로만 보고(만든 개수).
