# 방문 기록(나라·날짜·시간) 연결하기 — 구글 시트 + Apps Script

사이트는 서버가 없어서, 방문 기록은 **운영자의 구글 시트**에 쌓습니다. 한 번만 설정하면 됩니다(약 5분).

## 1. 시트 만들기
1. 크롬에서 https://sheets.new 를 열면 새 구글 시트가 만들어집니다 (채널용 구글 계정 권장).
2. 왼쪽 위 제목을 `시뮬라티오 랩 방문 기록`으로 바꿉니다.

## 2. 코드 붙여 넣기
1. 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
2. 왼쪽에 `Code.gs`가 열리면 안의 내용을 모두 지우고, 아래 주소의 내용을 전부 복사해 붙여 넣습니다.
   https://raw.githubusercontent.com/heekeunlee/simulatiolab/main/tools/analytics/apps-script.gs
3. 위쪽 💾(저장)을 누릅니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱**을 고릅니다.
3. 설정:
   - 설명: `방문 기록`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르면 권한 승인 창이 뜹니다 → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**. (내가 만든 스크립트라서 나오는 일반적인 안내입니다.)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/……/exec`)을 복사해서 Claude에게 알려 주세요. → `site/counter.js`의 `LOG_URL`에 넣고 배포하면 그때부터 기록됩니다.

## 비밀번호
- 기본은 `0001`입니다. 이 코드는 공개 저장소에 있으므로, 원하면 Apps Script 왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**에서 이름 `ADMIN_PW`, 값에 새 비밀번호를 넣으세요. 그러면 그 비밀번호만 통과합니다 (사이트 코드는 바꿀 필요 없음).
- 비밀번호는 구글 쪽에서 확인하므로 사이트 코드에는 들어 있지 않습니다.

## 기록되는 것 / 기록되지 않는 것
- 기록: 시각, 나라 코드(KR, US…), 본 페이지, 화면 언어, 휴대폰/컴퓨터, 그 브라우저의 오늘 첫 방문인지, 다른 사이트에서 왔다면 그 사이트 주소(예: www.youtube.com)
- 기록 안 함: IP 주소, 이름, 계정 등 개인 정보. 나라는 `api.country.is`(무료 서비스)가 방문자 IP로 판별해 나라 코드만 돌려줍니다.
- 테스트용 자동 브라우저와 로컬 테스트는 기록하지 않습니다.

## 코드를 고쳤을 때
Apps Script에서 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 반영됩니다 (URL은 그대로).
